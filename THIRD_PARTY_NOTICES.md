# Third-party notices and provenance

The engine and editor were extracted from Chartzap’s SaaS BI product, authored by
Nick Dainty. Chartzap owns the source; the owner approved this focused extraction
under MIT. No application routes, credentials, customer records, persistence code,
or private Git history are included.

## Generated parser

The grammar is part of the extracted language. The checked-in JavaScript parser
is generated by `@lezer/generator` (MIT); its runtime uses `@lezer/lr` and
`@lezer/common` (MIT). Generate with `pnpm generate` and the committed lockfile.
The grammar and emitted parser, not a copied application build, are shipped.

## Examples

`examples/atelier` is an original synthetic commerce model and hand-written test
data created for this project. Its studio names, orders, and values are fictional.
It is the public playground and PostgreSQL integration fixture.

`tests/fixtures/northwind.ts` contains schema metadata only, adapted from the
private source to preserve the original regression baseline. It has no row data.
Northwind table/column relationships can be compared with Microsoft’s official
[Northwind sample](https://github.com/microsoft/sql-server-samples/blob/master/samples/databases/northwind-pubs/instnwnd.sql).
Microsoft distributes the SQL Server samples under the

The notice is retained below for any derivative schema metadata. No Microsoft
